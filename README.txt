Инструкция по запуску проекта "Информационная система ломбарда"

1) Установите PostgreSQL и создайте пустую базу данных с именем "lombard_db".
2) Разверните структуру базы и тестовые данные. Для этого откройте терминал в папке с проектом и выполните команду:
   psql -U postgres -d lombard_db -f lombard_db.sql
3) Если пароль от вашей базы данных отличается от стандартного (1), задайте переменную окружения перед запуском:
   Windows: set DB_PASSWORD=ваш_пароль
   Linux/Mac: export DB_PASSWORD=ваш_пароль
4) Убедитесь, что у вас установлена Java 17. Запустите проект из корневой папки (где находится pom.xml) командой:
   mvn spring-boot:run
5) Откройте браузер и перейдите по адресу: http://localhost:8080
